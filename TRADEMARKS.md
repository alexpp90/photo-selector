## What you may do

- Refer to an app by name to describe it truthfully ("based on Blitzlens", "a fork of
  Jackpix", "compatible with Lensjet").
- Build and run unmodified or modified versions for yourself.
- Keep the Marks in an unmodified copy of the repository, its README and documentation.

## What needs permission

- Distributing a **modified** build — in an app store, a package repository, a website or
  otherwise — under any of the Marks, or with the Marks as its icon or branding.
- Using the Marks in a way that suggests the maintainer endorses, sponsors or provides your
  build, product or service.
- Using a name or logo confusingly similar to the Marks for a photo-culling product.

If you distribute a fork, give it a different name and icon, and state that it is based on
this project. That is all the MIT License requires plus this policy asks for.
