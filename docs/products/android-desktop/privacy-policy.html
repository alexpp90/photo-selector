Privacy Policy — Frameduel (Android Desktop)

Last updated: November 2026 · Deutsche Version unten

1. Summary

Frameduel (Android package com.photoselectortoolbox) is a free, open-source, 100% on-device photo culling and quality analysis application for Android tablets and desktop mode (Samsung DeX). Your photos, EXIF metadata, quality scores, and usage data never leave your device. The application requests zero runtime permissions, contains no analytics, no advertising SDKs, no crash-reporting telemetry, and no cloud backend.

2. Controller (Art. 4(7) GDPR)

Alexander Patz
Contact: see Legal Notice (Impressum) or via GitHub at github.com/alexpp90/photo-selector.

3. Data Processed by the Application

  • Photos, EXIF Metadata & On-Device Analysis (Local Only): You select folders explicitly using the Android System Storage Access Framework (SAF) folder picker (ACTION_OPEN_DOCUMENT_TREE). All sharpness, noise, exposure, subject, composition, and technique (OpenCV), and duplicate analyses run strictly locally on your device. No images, thumbnails, file paths, GPS coordinates, or EXIF tags are ever transmitted over a network by Frameduel. If you choose a folder that a cloud storage app provides, that app transfers and syncs the files under its own privacy policy; Frameduel itself sends nothing.
  • Local Score Cache & Preferences (Room & DataStore): Calculated image quality scores, detected technique facts, and star ratings are cached locally in an internal SQLite (Room) database so folders re-open quickly, and user preferences are stored in Android Jetpack DataStore. A star rating you give is also written into an XMP sidecar file next to the photo (RAW, TIFF), in the folder you chose, so other apps and anyone you share the file with can read it. It is written into a JPEG's own XMP metadata only while Write ratings into photos is on in Settings; that setting is off on a new install, and an installation that already wrote ratings into JPEGs before it existed keeps it on. You can clear the local score cache at any time in Settings → Cache → Clear Cache. Cloud auto-backup of the local score database and SAF folder grants is disabled so local file URIs and metadata are never uploaded to cloud backup services.

4. Legal Basis (Art. 6 GDPR)

Because all processing takes place strictly locally on your device at your initiative and no personal data is transmitted to the developer or any third party, no external processing of personal data occurs. Local storage access occurs solely to provide the features explicitly requested by you (Art. 6(1)(b) GDPR / § 25(2) No. 2 TDDDG).

5. Data Retention & Deletion

Cached scores can be cleared within the app's Settings screen at any time. Uninstalling the app immediately deletes all locally cached scores, preferences, and SAF folder access grants.

6. Your Rights under GDPR

Under the General Data Protection Regulation (Arts. 15–21, 77 GDPR), you have the right to access, rectification, erasure, restriction of processing, data portability, and to lodge a complaint with a supervisory authority. Because the developer receives or stores no personal data from your use of Frameduel, you retain full technical control over all data directly on your device.

7. This Website

This page and the Legal Notice are hosted on GitHub Pages (GitHub Inc., USA, certified under the EU-U.S. Data Privacy Framework). When you open them, GitHub may process technical access data such as your IP address in its server logs under its own privacy policy; the developer receives none of it. The app opens these pages only when you tap their link in Settings.

Datenschutzerklärung — Frameduel (Deutsch)

Stand: November 2026

1. Überblick

Frameduel (Android-Paket com.photoselectortoolbox) ist eine kostenlose, quelloffene Anwendung zur Fotoauswahl und Bildqualitätsanalyse, die ausschließlich lokal auf Ihrem Endgerät arbeitet. Ihre Fotos, EXIF-Metadaten, Qualitätsbewertungen und Nutzungsdaten verlassen zu keinem Zeitpunkt Ihr Gerät. Die App fordert keinerlei Laufzeitberechtigungen an und enthält weder Analyse-Tools noch Werbe-SDKs, Absturzberichte oder Cloud-Server.

2. Verantwortlicher (Art. 4 Nr. 7 DSGVO)

Alexander Patz
Kontakt: siehe Impressum oder über GitHub unter github.com/alexpp90/photo-selector.

3. Verarbeitete Daten auf dem Endgerät

  • Fotos, EXIF-Metadaten & Bildanalyse (ausschließlich lokal): Der Zugriff auf Fotoordner erfolgt ausschließlich über die vom Nutzer explizit im Android Storage Access Framework (SAF, ACTION_OPEN_DOCUMENT_TREE) ausgewählten Verzeichnisse. Sämtliche Berechnungen (Schärfe, Bildrauschen, Belichtung, Motiv-, Technik- und Bildkompositionsanalyse mittels OpenCV sowie Duplikaterkennung) finden vollständig lokal auf Ihrem Gerät statt. Wählen Sie einen Ordner, den eine Cloud-Speicher-App bereitstellt, überträgt und synchronisiert diese App die Dateien nach ihrer eigenen Datenschutzerklärung; Frameduel selbst sendet nichts.
  • Lokaler Bewertungs-Cache & Einstellungen (Room & DataStore): Berechnete Qualitätswerte, erkannte Aufnahmetechnik-Merkmale und Sternebewertungen werden lokal in einer internen SQLite-Datenbank (Room) zwischengespeichert; Einstellungen liegen lokal im Jetpack DataStore. Sie können den Analyse-Cache jederzeit in den App-Einstellungen (Settings → Cache → Clear Cache) löschen. Ein Cloud-Auto-Backup dieser Datenbanken ist deaktiviert. Eine von Ihnen vergebene Sternebewertung wird zusätzlich in eine XMP-Sidecar-Datei neben dem Foto (RAW, TIFF) im von Ihnen gewählten Ordner geschrieben; andere Apps und alle, denen Sie die Datei weitergeben, können sie dadurch lesen. In die XMP-Metadaten eines JPEG selbst wird sie nur geschrieben, solange in den Einstellungen Bewertungen in Fotos schreiben eingeschaltet ist; bei einer Neuinstallation ist das aus, und eine Installation, die schon vor dieser Einstellung Bewertungen in JPEGs geschrieben hat, behält sie eingeschaltet.
